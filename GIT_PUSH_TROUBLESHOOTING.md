# Git Push Troubleshooting Guide

## Problem: Large Files Exceed GitHub's File Size Limit

### Error Message
```
remote: error: File python-scraper/venv/lib/python3.9/site-packages/playwright/driver/node is 105.51 MB; this exceeds GitHub's file size limit of 100.00 MB
remote: error: GH001: Large files detected. You may want to try Git Large File Storage - https://git-lfs.github.com.
```

### Root Cause
Virtual environment files (venv/) contain large binary files that exceed GitHub's 100MB file size limit. These files should never be committed to version control.

   git reset --soft HEAD~1

### Prevention
- Always create a comprehensive .gitignore file before starting development
- Never commit virtual environments, node_modules, or other dependency directories
- Use `git status` to review what files are being staged before committing
- Consider using `git add .` with caution - prefer adding specific files or directories

### Key Files to Always Exclude
- `venv/` or `env/` (Python virtual environments)
- `node_modules/` (Node.js dependencies)
- `.env` files (environment variables)
- `__pycache__/` (Python cache files)
- `*.log` files (log files)
- Build outputs (`dist/`, `build/`, `.next/`)
- OS-specific files (`.DS_Store`, `Thumbs.db`)

### Alternative: Git LFS
For legitimate large files that need to be versioned, consider using Git Large File Storage (LFS):
```bash
git lfs track "*.psd"
git lfs track "*.zip"
git add .gitattributes
git commit -m "Add LFS tracking"
```
